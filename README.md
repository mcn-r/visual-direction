# Visual Direction

A collection of visual design work focused on storytelling, cultural aesthetics, and experience-driven visual systems.

## Overview

This repository highlights design work across graphic design, visual storytelling, and conceptual interface ideas.

The focus is on creating visuals that feel intentional, immersive, and culturally grounded — prioritizing mood, composition, and audience connection.

---

## Areas of Exploration

• promotional and event-based design (flyers)  
• visual storytelling and branded concepts  
• interface and layout systems  
• experimental design for digital experiences  

---

## Included Work

### Flyers

Designs focused on strong visual identity, selective information, and creating a clear sense of atmosphere.

### fw Infomercial Concept

A visual exploration of how the fw world can be translated into a stylized promotional format.

### App Grid Concept

An interface-driven concept exploring layout systems, structure, and visual organization.

---

## Approach

This work treats design as part of a system rather than isolated visuals.

Each piece explores how composition, color, and structure influence perception and engagement.
